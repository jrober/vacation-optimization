Live prices — how to plug in real APIs later

Keys stay in this page session only and are not saved. Live fetch functions are placeholders until wired to a server proxy.

Placeholder fetch functions (in source)

fetchLiveFlight() → Duffel Offers API (POST https://api.duffel.com/air/offers).
fetchLiveHotel() → your hotel booking API for nightly rates by date.
fetchLiveCruise() → cruise line / aggregator API for sailing price by departure date.
Each should return a per-date price in the same shape as the estimate functions, or null to fall back to estimates. Keep keys out of git — use environment variables / a server proxy in production, never a client-side key in a public page.

How the estimate works

  • Flight: preset base round-trip per adult, adjusted by weekday (Tue/Wed cheapest, Fri/Sun dearest), season by month, and a deterministic pseudo-random variation per date + destination. Children at 75%. Direct-only adds 8% (estimate).
  • Hotel: preset nightly rate × star multiplier (3★ 0.85, 4★ 1.00, 5★ 1.35), with a Fri/Sat-night premium, season, and per-date variation.
  • Cruise: preset base per person by length category — Short ≤4 nights (50% of long base), Medium 5–6 nights (72%), Long 7+ nights (100%) — children at 50%.
  • Taxes/fees (estimate): 12% on hotel, 8% on cruise. No flight tax in this model.
  • Bundle discount (estimate, not a real offer): 10% off hotel when flight + hotel are both checked.
  • Theme parks (estimate only): 1-day adult base — Walt Disney World $165, Disneyland $160, Universal Orlando $140, Universal Hollywood $130, Legoland Florida $110, SeaWorld Orlando $105; children at 90% of adult. Multi-day per person = 1-day price × days0.75. No tax added to park tickets in this model. Check the park's official site for exact prices.
  • Total = flight + hotel + cruise (only if cruise checked) + theme parks (only if theme parks checked) + taxes − bundle discount. A component contributes to a total only when its checkbox is on.
    • Per-person = total ÷ (adults + children). Savings = most-expensive window total − this window total.
  • Book now or wait (estimate only): bottom quartile of totals in your window = “Low vs typical”, middle = “Typical”, top quartile = “High vs typical”. This is a comparison inside your window, not a real price prediction.
