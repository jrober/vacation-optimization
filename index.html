✈️ Vacation Optimizer

Enter a destination and a flexible window. We compare every possible departure date in that window, add up flight + hotel + cruise, and rank the cheapest trips first — total cost first, breakdown second.

New in v3 — Exact options (demo dataset). Below the estimate results there is an “Exact options” section with real flight and hotel offers found on 2026-11-04 for SLC → Cancun, Jan 27–Feb 3, 2027, 2 adults. Those are a snapshot, not live prices — re-check before booking. Everything else in the estimate results is still an estimate. Estimates only — not live prices. All prices below are deterministic estimates for comparison, until real APIs are connected in the “Live prices” section. Do not book on these numbers alone. The “book now or wait” indicator is a quartile comparison inside your own window, not a real price prediction.

📱 Install on iPhone

This app is installable — no App Store needed. Once installed it opens full-screen from your Home Screen and works offline for the app itself (prices are still estimates).

  1. Open this app in Safari on your iPhone, from an https:// site (for example GitHub Pages — see the README). Opening the raw index.html file will not install.
  2. Tap the Share button (the square with an arrow pointing up) in Safari's toolbar.
  3. Scroll down and tap Add to Home Screen, then tap Add in the top-right.
  4. Open it from the new Vacation icon on your Home Screen.

Tip: if you do not see “Add to Home Screen”, make sure you are in Safari (not an in-app browser) and on an https:// page.

Live prices — how to plug in real APIs later

This prototype deliberately does not call live APIs and does not store keys in code. To go live, fill in the fields below (they stay in your browser only, in this page session) and implement the placeholder functions in the page source. Until then, estimates are used.

Placeholder fetch functions (in source)

fetchLiveFlight() → Duffel Offers API (POST https://api.duffel.com/air/offers).
fetchLiveHotel() → your hotel booking API for nightly rates by date.
fetchLiveCruise() → cruise line / aggregator API for sailing price by departure date.
Each should return a per-date price in the same shape as the estimate functions, or null to fall back to estimates. Keep keys out of git — use environment variables / a server proxy in production, never a client-side key in a public page.

How the estimate works

  • Flight: preset base round-trip per adult, adjusted by weekday (Tue/Wed cheapest, Fri/Sun dearest), season by month, and a deterministic pseudo-random variation per date + destination. Children at 75%. Direct-only adds 8% (estimate).
  • Hotel: preset nightly rate × star multiplier (3★ 0.85, 4★ 1.00, 5★ 1.35), with a Fri/Sat-night premium, season, and per-date variation.
  • Cruise: preset base per person by length category — Short ≤4 nights (50% of long base), Medium 5–6 nights (72%), Long 7+ nights (100%) — children at 50%.
  • Taxes/fees (estimate): 12% on hotel, 8% on cruise. No flight tax in this model.
  • Bundle discount (estimate, not a real offer): 10% off hotel when flight + hotel are both checked.
  • Total = flight + hotel + cruise + taxes − bundle discount. Per-person = total ÷ (adults + children). Savings = most-expensive window total − this window total.
  • Book now or wait (estimate only): bottom quartile of totals in your window = “Low vs typical”, middle = “Typical”, top quartile = “High vs typical”. This is a comparison inside your window, not a real price prediction.
